# Study Methodology

## First attempt

1. Restate the problem and identify its input constraints.
2. Write down the brute-force approach before optimizing.
3. Implement the solution without looking at an existing answer.
4. Add tests for examples, boundaries, and previous mistakes.
5. Record time and space complexity in the class documentation.

## Review

Mark a problem as `Review` when the main idea was not found independently. Revisit it after 1, 3, 7, and 14 days. Prefer reimplementing the solution over rereading it.

## Notes

Keep routine explanations in JavaDoc. Add a document under `docs/solutions` only when a problem has multiple valuable approaches, subtle edge cases, or a reusable pattern.
